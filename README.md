# 🎛️ Faust DSP: From Basics to Functional Audio

Welcome to this progressive tutorial on **Faust** (Functional Audio Stream). 
This repository is designed to guide you through DSP (Digital Signal Processing) using the functional programming paradigm applied to audio.

## 🎯 Goal
The goal is not just to write code, but to **think in block diagrams**. In Faust, every expression is a signal processing block, and the code is simply the description of how these blocks are wired together.

## 📂 Tutorial Structure
The path is divided into progressive folders. It is recommended to follow the numerical order.

- 📁 `01_basic_examples/`
  - `01_routing_and_flows.md` *(Signal flow, sequences, parallels, split and merge)*
  - *(More basic examples will follow...)*

## 🛠️ Prerequisites
To follow these tutorials, no complex local installation is required. You can use the **[Faust Web IDE](https://faustide.grame.fr/)** directly, which allows you to write code, view the generated block diagram, and listen to the result in real-time in your browser.

## 🚀 How to use this repo
1. Open the `.md` file for the lesson.
2. Copy the Faust code blocks into the online editor.
3. Click **Run** and observe the *Block Diagram* to visually see what the code describes.
